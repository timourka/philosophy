# Конспект с микрофоном

Локальный web-редактор: распознанная речь даёт продолжение, Tab принимает одно слово. Текст пользователя автоматически не переписывается.

## Запуск

Из корня репозитория:

```sh
python mic-notes/serve.py
```

Открыть http://127.0.0.1:8766 в актуальном Chrome или Edge. Сервер доступен только на этом компьютере. Остановить: Ctrl+C в терминале.

1. Подтвердить использование браузерного сервиса распознавания и нажать «Начать слушать».
2. Разрешить микрофон в браузере; используется выбранный в браузере/Windows микрофон по умолчанию (для встроенного микрофона ноутбука выберите его в настройках сайта).
3. Печатать заметку; Tab дописывает одно слово, в том числе хвост частично набранного. Escape сбрасывает текущие подсказки. Без подсказки Tab остаётся обычной навигацией.
4. Для ошибки термина добавить пару в «Словарь исправлений». Различия между пересказом и речью не заучиваются автоматически.
5. «Скачать .md» сохраняет резервную копию. Текст, название и словарь автоматически хранятся в localStorage этого браузера и origin. Очистка данных браузера их удалит.

## Контекст и ограничения

- Выбор ASR альтернатив учитывает совпадение хвоста заметки с началом распознанной фразы. Это эвристика, не смысловая языковая модель.
- Явный словарь исправляет только гипотезы. Браузерам с `SpeechRecognitionPhrase` передаются последние термины и словарь. Поддержка contextual phrases не универсальна; локальный словарь работает без неё.
- Подсказки словесные: пунктуация распознанной речи при токенизации не переносится. Пользователь расставляет её самостоятельно.
- После отмены ввода текст отменяется нативно, но очередь подсказок не откатывается. Можно нажать Escape и продолжить с новой гипотезой.
- Это не обучение ASR и не полноценная семантическая коррекция акустической модели. Адаптер отделён от ядра для будущей замены на локальный Whisper/Vosk.
- Браузерный `continuous` может остановиться сам; приложение не включает микрофон повторно без действия пользователя.

## Приватность

Микрофон выключен при открытии. Приложение аудио не сохраняет. Web Speech может отправлять звук сервису браузера, даже при localhost; для Chrome это может быть сервис Google. Офлайн-режим не заявлен: проверенный статус локального пакета ru-RU был `downloadable`, не `available`; пакет не устанавливался. Не используйте облачное ASR для конфиденциальной речи без согласия её участников.

## Проверка

```sh
node --test mic-notes/core.test.mjs mic-notes/speech.test.mjs
```

26 тестов: очередь final/interim, одно слово, partial, русский регистр/ё/дефисы, сопоставление набранного после поступления гипотезы, продолжение из хвоста заметки, отсутствие повтора final, явные исправления, отсутствие автоматической записи микрофона, остановка и ошибки.

В браузере проверены тестовая фраза (не реальная запись), Tab, частичное слово, Escape, локальное сохранение, словарь, нативная отмена ввода и загрузка интерфейса. Микрофон не включался; фактическая аудиотранскрипция, качество ru-RU и задержка на живой лекции остаются непроверенными.
