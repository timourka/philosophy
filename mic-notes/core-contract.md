# NoteAssistant — контракт ядра для UI

Модуль: `mic-notes/core.mjs`. Чистые функции внутри класса, без DOM, сети и микрофона. UI сам решает, когда включать распознавание, и сам подставляет гипотезы.

```js
import { NoteAssistant } from './core.mjs';
const notes = new NoteAssistant();
```

## Методы

### `updateHypothesis({ id, final, alternatives }, contextText)`

Кладёт гипотезу в очередь подсказок. Текст конспекта не меняет.

- `id` — стабильный идентификатор результата ASR.
- `final` — `true` дописывает фразу в очередь; повтор того же `id` и текста игнорируется. `false` заменяет предыдущий interim целиком.
- `alternatives` — `[{ text, confidence? }]`. Выбирается фраза, чей начало совпадает с самым длинным хвостом `contextText`. При равенстве берётся более длинная. `confidence` ядро не использует.
- `contextText` — текущий конспект. Уже написанный префикс фразы в очередь не попадает.

Пустая речь (нет слов) ничего не добавляет. Сравнение безучётно к регистру и к паре е/ё. Пунктуация не входит в слова; дефис внутри слова сохраняется.

### `suggest(text, cursor) → { insertion, display } | null`

Одно следующее слово очереди для позиции `cursor` в `text`. `null`, если подсказывать нечего.

- `display` — слово целиком, для подсветки.
- `insertion` — то, что вставляется в `cursor`. Если слева от курсора набран префикс этого слова, вставляется только хвост. Иначе перед словом ставится пробел, если символ перед курсором не пробел и курсор не в начале.

### `accept(text, cursor) → { text, cursor } | null`

Вставляет ровно одно слово и сдвигает очередь. Текст после курсора сохраняется. Возвращает новую строку и курсор сразу после вставки. `null` — Tab ничего не делает и не блокируется ядром.

### `dismiss()`

Сбрасывает текущую очередь, не трогая конспект. Повтор уже виденной final её не возвращает. Новая гипотеза с другим `id` снова даёт подсказку.

### `setCorrections([{ from, to }])`

Явный словарь замен. Пара может покрывать одно слово или несколько; более длинная пара проверяется первой. Замена применяется только к распознанной фразе до подсказки. Расхождение конспекта с речью ошибкой не считается и текст пользователя не переписывается.

## Что UI делает сам

- Не вызывает эти методы из кода, который запускает микрофон без явного действия пользователя.
- Показывает `display` как inline-подсказку и вставляет результат `accept` только по Tab.
- Escape вызывает `dismiss`. При `null` Tab и Escape остаются обычными клавишами редактора.
- Передаёт в `contextText` текст до курсора, если подсказка должна продолжать именно его.
