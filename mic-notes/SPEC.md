# Конспект с микрофоном — требования и границы

## Пользовательский сценарий

1. Открыть редактор на localhost. Микрофон по умолчанию выключен.
2. Явно разрешить браузерному сервису распознавание и нажать «Начать».
3. Печатать конспект самостоятельно. Распознанная речь — лишь источник подсказок.
4. Tab принимает одно следующее слово, включая завершение частично набранного слова. При отсутствии подсказки Tab не блокируется. Escape отклоняет текущую подсказку.
5. Редактирование и курсор не должны приводить к автоматической замене текста; undo сохраняется.
6. Исправления терминов задаются явно парой «распознано → правильно». Несовпадение с конспектом не считается доказательством ошибки: пользователь может пересказывать.
7. Контекст: последние слова конспекта помогают выбирать ASR альтернативу; словарь и недавние термины передаются как contextual phrases, только если API их поддерживает. Это biasing, а не дообучение модели.
8. Локальное автосохранение заметки и словаря; экспорт Markdown. Аудиозаписи приложение не сохраняет.

## Реализация первой версии

- Локальная web-страница, native browser SpeechRecognition / webkitSpeechRecognition, ru-RU, interimResults, maxAlternatives.
- Отдельные адаптер ASR и чистое ядро сопоставления: возможность позже подключить локальный Whisper/Vosk без переделки редактора.
- При отсутствии API или сетевой ошибке — ясное сообщение, сохранённый текст остаётся доступен.
- Демонстрационный ввод распознанной фразы отделён от настоящего микрофона, не выдаётся за реальную транскрипцию.
- Браузер может передавать звук внешнему сервису. Это явно раскрывается до старта. Офлайн-режим не обещается без проверки ru-RU пакета.
- Постоянно видимый индикатор работы микрофона, кнопка остановки. Остановка при уходе со страницы.

## Проверка

Unit tests ядра: одно слово за Tab, частичное слово, совпадающий префикс, альтернативы, явные исправления, повторные final/interim, регистр/ё, пустая речь, редактирование в середине.
Browser tests: текст не меняется сам; ввод/Tab/Escape/undo; сохранение и экспорт; отключённый по умолчанию микрофон; информирование о внешнем ASR; обработка неподдерживаемого API.

Реальная акустическая точность и разрешение микрофона требуют отдельной пользовательской проверки. Тестовый ввод не заменяет её.
