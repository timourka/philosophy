# М. П. Волков — «Античная наука как социокультурное явление. Проблема генезиса»

Ульяновск: УлГТУ, 2008. ISBN 978-5-9795-0160-4.

Черновое распознавание 67 сканов разворотов встроенным Windows OCR, язык — русский.

- `all_text.txt` — общий текст с разделителями по именам исходных сканов.
- `spread_0001.txt` … `spread_0067.txt` — текст каждого скана отдельно.
- `manifest.json` — результаты обработки и число символов для каждого скана.

Текст не вычитан. Возможны ошибки распознавания, переносов и порядка строк, особенно возле корешка. `spread_0001` и `spread_0002` — повторные сканы одного разворота; оба сохранены в черновом тексте. Количество сканов не подтверждает полноту и последовательность всех печатных страниц.

Изображения исходных сканов и программы управления сканером в этот набор не включены; они сохранены локально в `D:\philosophy\scans`.
