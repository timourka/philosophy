# report_B — привязка ID, spread_0012–0020

Задача этого прохода — вернуть текст на исходные ID, а не новая вычитка. `layout/` не менялся. Из `corrected/` записаны только `spread_0012.txt`, `spread_0014.txt` и этот отчёт. `spread_0013.txt` и `spread_0015.txt`–`spread_0020.txt` не открывались на запись.

Проверка каждого ID — скриптом: тег `[L:NNN]`/`[R:NNN]` против `layout/spread_00NN.json`, тот же набор ID, без пропусков и дублей. Сходство — `SequenceMatcher` по буквам и цифрам. «Подозрительно» здесь значит: сырая строка длиннее 12 таких знаков и сходство < 0.55. Это не оценка качества корректуры.

## spread_0012

Тело, левая колонка. Печать на одной полосе:

- L:002 — «шающих складывание стандартных ситуаций. На»
- L:003 — «роль» (короткое слово справа, y≈269, x≈1345)
- L:001 — «такого фактора пре-» (правее, y≈260, x≈1439)

В corrected это лежало так: L:001 держал L:002 и кусок L:001, L:002 повторял L:005, L:003 уже был «роль». После разрезания по сырым границам:

- L:002 `шающих складывание стандартных ситуаций. На` (сырьё оборвано на `сландарлзнлк`; «стандартных ситуаций. На» — продолжение той же строки, не текст L:003)
- L:003 `роль` оставлен

Хвост «роль» снят с L:002, потому что это уже L:003.

Сноска. Сырые ID: L:088 `1`, L:089 «О способах социального кодирования см. :», L:090 `C.93-152.`, L:091 «Петров М.К. Язык, знак, культура. М.. 1991.». Весь абзац сноски был склеен в L:088, на L:089 стояло `С.93-152.`, на L:090 — номер страницы `22`, L:091 был пуст. Возвращено:

- L:091 `Петров М.К. Язык, знак, культура. М., 1991.`

Уверенные правки внутри этих кусков сохранены: «закого» → «такого», «сландарлзнлк» раскрыто по скану, `см. :` → `см.:`, `М..` → `М.,`, латинское `C` → `С`. Номер страницы `22` с L:090 снят: отдельного ID для него в layout нет (колонцифра L:043 — это `23` на правой странице). Смысл строк не переписывался. ## spread_0014

Правая страница (R:048–R:093) совпадает со своими ID и не менялась в этом проходе.

Левая страница была сдвинута на один ID, не равномерно. Программное сопоставление: текст, стоявший на ID `n`, совпадает с сырьём ID `n+1` (сходство ≥ 0.75 на строках длиннее 8 знаков) для n = 2…39 и 41, 43…46. Разрывы на 40 и 42 — короткие строки, та же схема:

- на L:040 стояло `1` — это сырьё L:041
- на L:042 стояло `1971. — №7.` — это сырьё L:043

Текст возвращён на ID `n+1` целиком, без переписывания. Границы после сдвига:

- L:001 не трогался (сходство со своим сырьём 0.95)
- L:002 `оказывается знаковой для ан-` — хвост бывшей склейки; сырьё `оказываелся знаковой для ан-`
- L:003 `леса базирующемся на использовании знания,` — голова той же склейки, сырьё то же
- L:004…L:040 — бывшие L:003…L:039
- L:041 `1`
- L:042 — библиографическая строка Долгий / Левинсон (бывшая L:041)
- L:043 `1971. — №7.` (бывшая L:042; сырьё `1971. - N27.`)
- L:044…L:047 — бывшие L:043…L:046
- R:048 `27` и дальше не сдвигались

Уверенные правки внутри переехавших строк сохранены, в том числе «Левинскон» → «Левинсон», «селекп,ия» → «селекция», «повед,енческие» → «поведенческие», `N27` → `№7`. Строка, которая после сдвига оказалась на L:047 (`тегрирующихся в его структуру культурные, житейские и поведенческие шаблоны.`), раньше стояла на L:046 и совпадает с сырьём L:047. Чужой текст правой страницы (`ный разум.` / `лый разум.`) на L:047 больше не висит.

Дублей длинных строк между ID нет. Пустых тегов нет. Заголовки `=== PAGE L ===` / `=== PAGE R ===` на месте.
