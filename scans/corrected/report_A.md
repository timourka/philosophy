# report_A — сдвиг ID на spread_0004 и spread_0005

Проверены `corrected/spread_0001.txt`–`spread_0011.txt` против `layout/spread_XXXX.json`. Число ID и множество ID не менялись. Строки не перенумеровывались, не удалялись и не склеивались. Повторной вычитки страниц не было: две области сверены со сканом только чтобы не положить текст на чужой ID.

## Что было сломано

Исправленный текст съехал на соседний ID. Сходство с «своей» строкой layout падало ниже 0.55, с соседней — поднималось выше 0.8. Так `audit_correction.py` и набрал 31 подозрительную строку в 0004 и 35 в 0005.

- **0004, ID 059–088.** Текст, лежавший на ID k+1, возвращён на ID k. Это один сдвиг на строку. ID 089 был склейкой хвоста сноски с 088; склейка снята.
- **0005, ID 020–043 и 048–057.** Тот же сдвиг на одну строку, начиная с 019. ID 044–046 — три OCR-куска одной печатной строки, их нельзя было сдвигать тем же шагом.

0001, 0002, 0003, 0006–0011 такого сдвига не имеют: у каждой непустой правки лучшее совпадение — собственный ID. В 0001, 0002 и 0009 порядок строк в файле не совпадает с порядком массива layout (переставлены пары соседних ID). Это порядок колонок, не сдвиг текста; ID не трогал.

## Что сознательно не положено на ID

- **0004, между 058 и 059** на скане есть строка без ID: «осуществленными в будущем предметных взаимодействий, способов самоор-». 059 начинается с «ганизации». Строку на 059 не записывал: иначе снова сдвиг. Факт отмечен в пометке 089.
- **0004 / 089** — только «ское знание. М., 2000.» (хвост «Теоретиче-» с 088). Раньше это было приписано к 088.
- **0005 / 019.** Layout «уз н,зура,» на скане отдельной строкой не читается (слева от 018 пустой абзац). ID сохранён, стоит пометка. Текст следующей строки стоит на 020: «грамм деятельности…».
- **0005 / 044–046.** На скане это одна строка: «виду деятельности набором соматических и психо-». Полный текст лежит на 044 (первый ID фрагмента). 045 и 046 не удалены: пометка, что layout-кусок входит в 044 и отдельно не повторяется. 047 — следующая печатная строка, «физиологических параметров;».
