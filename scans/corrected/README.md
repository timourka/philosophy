# Корректура OCR книги Волкова

М. П. Волков. «Античная наука как социокультурное явление. Проблема генезиса». УлГТУ, 2008.

## Файлы

- `all_text_corrected.txt` — собранный текст 67 сканов. Между сканами разделитель form feed; внутри сохранены PAGE L/R и исходные идентификаторы строк.
- `spread_XXXX.txt` — исправленный текст отдельного разворота.
- `validation.json` — проверка покрытия: 67 файлов, 6035 исходных идентификаторов; 1060 строк отличаются от исходного OCR (это число строк, не отдельных исправлений).
- `report_*.md` — отчёты этапов. Старые отчёты могут описывать промежуточные и впоследствии исправленные состояния; для 54–57 итоговый — `report_F_final.md`.

Сырой OCR сохранён без изменений в `../ocr/`. Геометрия исходных слов и строк — в `../layout/`. Идентификатор — номер строки OCR, а не номер печатной строки: OCR иногда дробил один печатный ряд на несколько фрагментов или полностью пропускал ряд. L/R — геометрическая оценка стороны разворота (53% ширины), не гарантированная пагинация книги.

## Как получен результат

Параллельная корректура моделью `cursor/grok-4.7@500k`, затем восстановление ошибочно сдвинутых соответствий ID и повторная структурная проверка. Сохранялись строки и дефисные переносы; авторский текст не должен был перефразироваться. Сканами проверялись выборочные спорные места. Это не сплошная визуальная сверка книги и не издательски вычитанная версия.

## Известные ограничения

- Ошибки и непроверенные чтения остаются. Сомнения помечены в тексте и отчётах; некоторые спорные слова оставлены в исходном виде.
- Первые два скана повторяют один разворот; оба сохранены для прослеживаемости.
- В нескольких местах исходный OCR пропустил печатные строки. Они описаны в отчётах/пометках; наличие всех ID не доказывает полноту всего печатного текста.
- Фрагменты сносок/колонок и отдельные разорванные строки могут требовать ручного чтения по изображениям.
- Сохранение ID проверено программно; смысловая точность каждого исправления этим не доказывается.

Для цитирования сверяйте фрагмент и номер страницы с оригиналом. Прежний общий OCR `../ocr/all_text.txt` не заменён.
