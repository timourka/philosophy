# notes_05. Развороты 0036–0043

Источники: `scans/corrected/spread_0036.txt`–`spread_0043.txt`. Порядок строк совпадает с `layout/spread_0036.json`–`0043.json` (сначала левая страница, затем правая; у 0041 правой полосы нет). Соседи `spread_0035` и `spread_0044` использованы только на стыках фраз и в текст части не включены, кроме сохранённого обрыва. Выход: `scans/readable/part_05.md`.

Объём. После склейки переносов в corrected 5711 слов; в `part_05.md` 5950 (справки сносок чуть длиннее библиографических обрывков). По словам длиной от 5 букв совпадает 3408 из 3800 (89,7%). Оставшиеся «пропуски» — не выкинутые абзацы, а осколки OCR, которые в редакции стали нормальными словами: `лредставлен`, `ноновской`, `отвержеhooykaas`, `60роборческие`, `антропоморфизируощего`. Содержательных лакун сверх обрывов скана нет.

## Склейки переносов (не все, только небанальные)

`боро- / борческие` → богоборческие (OCR «бороборческие»: «р» вместо «г»). `не- / обходимости` через разрыв сноски Hooykaas. `религиозно- / мифологического`, `социально- / психологический`, `научно- / рационалистического` (в OCR слитно «научнорационалистического»). `пред- / ведической` прочитано как «исторической предшественницы — ведической», не как «предведической». `очеловечива- / пито` → очеловечиванию. `познавагельному действто` → познавательному действию. `под- / талкивая`, `под- / чинена`, `описа- / пых` → описаниях. `Филок- / лета`. `внугри` → внутри, `себе` без «подобных» дописано только там, где OCR даёт «с себе / подобными». `даст` → даёт (литература). `замкнугая` → замкнутая. `Геомелрический` → Геометрический. `организуощего` → организующего. `внугренним` → внутренним. `ластически` в начале строки с. 85 → Пластически (буква «П» в зоне сноски).

Имена: `Кассан` + «дра» = Кассандра. `Ату` оставлена как в OCR (богиня безумия; обычное Ата/Атэ не подставлено). `Минном` оставлено с пометой, что обычно Мин. `Семенцова` не сверялась с каталогом. `Изогш` → Изогиз. `Ор. Новицкого` не заменено на «О.». `Ф. Ф. Зелинского` — инициалы по обычному написанию; в OCR «Ф. Ф. Зелинского» читается уверенно на с. 71.

Латынь и термины сохранены: *techne*, *episteme*, экфрасис, теменос, сансара, нирвана, дхармы. Стихи (Ночь у Лосева, «Илиада» VIII 555–559, Филоктет) — отдельными строками, не в прозу.

## Чего не видно и не дописано

- Номер страницы у Щербатского: «Пг., 1919. с» без цифры. В тексте: `[реконструкция: номер страницы в OCR оборван после «с»]`.
- Год Полевого на с. 84 оборван «М., 19», рядом в зоне сноски «1984» — год взят оттуда, помечен в сноске.
- У цитаты космоса-«инструмента» на с. 83 открывающей кавычки в OCR нет, закрывающая есть. Кавычка не добавлялась.
- Сноски с. 83 (Лосев С. 50 и Аверинцев С. 63) без номеров в основном тексте; привязка в `[^p05-26]` оговорена как вероятная, не как факт набора.
- С. 81 в файле 0041 нет. Текст не восполнялся.
- Стык 0041→0042 начинается с «щение греков» — левый край слова на скане обрезан. Не восстановлен.
- Последняя строка части: «заставляет рас-».
