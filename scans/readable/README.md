# Связная читательская редакция

Основной файл — `book_readable.md`. Это контекстная редактура OCR: восстановлены слова и абзацы, отдельно оформлены примечания, технические ID убраны. Это полный текст обработки, не конспект; оригинал и построчная расшифровка остаются в соседних папках.

Редакция не является факсимильно точным научным переизданием: в тексте есть помеченные реконструкции, возможны остаточные ошибки и редакторские изменения. Цитаты для научной работы сверяйте с печатным изданием.

При интеграции исправлены ошибочные утверждения агентов о пропущенных страницах 81–82: в исходном corrected/spread_0041 есть обе стороны, а 0042 начинается с 82. Также по исходному тексту восстановлен стык «предполагает признание наличия пустот»; вставка про «волос» в этом месте исключена как не соответствующая исходнику.

В библиографии по имеющимся данным отсутствуют позиции 78–122. Они не сочинялись. Сомнительные реконструкции обозначены в тексте. Общая словарная метрика QA — вспомогательная, а не доказательство буквенной полноты.

Сборка: `python scans/readable/assemble_readable.py`, затем `python scans/readable/repair_integration.py`. Вторая команда обязательна: устраняет выявленные ошибки интегратора и восстанавливает пять вводных сносок. Проверены 198 уникальных определений сносок, без ссылок на отсутствующие определения.

`part_*.md`, `pilot.md` и `notes_*.md` — промежуточные материалы. Старые утверждения о потерях страниц в QA/отчётах, противоречащие разделу integration_repairs и этому README, отменены. Текст продолжает нуждаться в осторожности при цитировании; утверждение о полностью безошибочной вычитке не делается.
