# G — восстановление привязки текста к ID

Развороты `spread_0064`–`spread_0067`. Источник геометрии — `layout/*.json` (`id`, `text`, `words.x/y`). Корректура сохранена; номера ID не перенумеровывались. Фрагменты одного печатного ряда оставлены на исходных ID.

Признак сдвига: множество ID совпадает, но текст corrected не совпадает со словами своего ID и совпадает со словами соседа. Восстановление — по совпадению токенов с `line.text` / `words`, при низком сходстве — исходный фрагмент с пометкой.

## spread_0064

Спорные ID 29 и 30 — два куска одного ряда библиографии (п. 2), а не две строки.

| ID | x | слова layout | текст после восстановления |

| 28 | 1997 | начало п. 2 | `2. Аверинцев С. Греческая «литература» и ближневосточная «словесность»` |

Корректура склеила оба куска в ID 29 и подставила `3.` в ID 30. Номер `3.` уже есть в ID 17 (`.3.`). Полный ряд на один ID не дублировался. OCR: `N98` → `№8`.

## spread_0067

ID 58–74 — правая полоса, цитаты. Corrected сдвинул каждый фрагмент на соседний ID и дважды записал концовку Тарнаса (ID 71 и ID 73) и подпись (ID 72 и ID 74).

Восстановлено по словам своего ID, правки OCR сохранены (`науку`, `Греки`, `Виндельбанд`, `Древние`, `вдохновения`, `глубоко`, `характера`, `должны`, `Тарнас`):

- 58 `изобрели науку. Они ее и в самом деле` — не вся фраза про греков
- 59 `Греки – словно чудом –` — левый кусок того же ряда (x=2070), не продолжение «изобретают»
- 60 строка «изобретают…»; 61 `научный метод.`; 62 `А. Боннар`
- 63–64 Боннар (язык / «проникнуты…»); 65 `В. Виндельбанд`
- 66–70 цитата Тарнаса по своим строкам
- 71 `е чем` + пометка AMBIGUOUS (см. ниже)
- 72 `приступить изучению характера собственного мышления, мы должны`
- 73 `внимательно всмотреться в мышление греков.`
- 74 `Р. Тарнас`

Дубли полного ряда сняты: ID 71 больше не копия ID 73, ID 72 больше не копия подписи.

### Неоднозначно

**0067 ID 71.** Слова layout: `е` (x=3235) и `чем` (x=3290), хвост строки ID 70 (`…что, п`). Корректор читал этот хвост как `чем`. Целого слова «чем» в боксе нет, буква `е` может быть мусором OCR. Восстановлен исходный фрагмент:

`е чем  [AMBIGUOUS: исходный фрагмент строки; корректор читал «чем»]`

Не выдумано продолжение и не перенесена сюда строка ID 73.
