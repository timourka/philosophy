# Итоговая электронная версия — редакция 1

М. П. Волков. «Античная наука как социокультурное явление. Проблема генезиса». Ульяновск: УлГТУ, 2008.

## Читать

- `Волков — Античная наука.md` — основной читательский файл.
- `Волков — Античная наука.txt` — тот же текст в UTF-8.
- `manifest.json` — состав и нерешённые повреждения.

Включены 66 сканов из 67: `spread_0002` — повтор первого разворота, исключён только из читательской версии. Служебные ID и девять помеченных дублирующих/ложных OCR-фрагментов убраны; четыре подтверждённых добавления (включая пропущенные строки и отточие) включены. Исходные переносы строк оставлены, чтобы не повредить слова и сноски автоматической склейкой. Заголовки «Скан» и «Левая/Правая страница» редакторские, не часть книги.

## Что доработано

Сомнительные места из финальных журналов A/B/C сверены со сканами. Восстановлены пропуски, сняты неподтверждённые домыслы, отделены верхние индексы и куски одной печатной строки от отдельного текста. Начало строки 0005 R044 («сложности вида деятельности…») дополнительно прочитано по полному изображению после неудачного обрезанного кропа.

Техническая версия со всеми исходными ID, включая исключённый дубль и артефакты, сохраняется в `../corrected/`. Журналы решений — `../corrected/final_decisions_A.md`, `final_decisions_B.md`, `final_decisions_C.md`. Результаты ранних этапов могут содержать уже отменённые предположения.

## Неустранимое по имеющимся сканам

На `spread_0031` правая страница, строки R047–R049: окончания скрыты загибом листа. В тексте стоят три пометки `[неразборчиво: загиб страницы]`. Их восстановление без домыслов требует нового скана этого участка. Не подставлялись слова лишь по грамматике или контексту.

Это итоговая версия текущей обработки, а не гарантия буквенной точности каждого знака: сплошная ручная сверка всей книги не выполнялась. Для научного цитирования необходимо сверять цитату и печатный номер страницы с оригиналом. Сохранены также возможные опечатки печатного издания.

## Воспроизводимость

Из корня репозитория: `python scans/build_corrected.py`, затем `python scans/publish_final.py`. Проверены все 6035 исходных ID в 67 технических файлах; читательская сборка проверяет состав и три явных повреждения.
